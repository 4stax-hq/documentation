# Memory types

| Type | Description |
|------|-------------|
| `preference` | How you like to work |
| `fact` | Stable facts about you or your projects |
| `decision` | Architectural or strategic decisions |
| `summary` | Compressed session summaries |
| `instruction` | Standing directives for AI behavior |
